# Sujay Kumar — Portfolio

Backend Java · Spring Boot · Oracle Fusion.

Live project UIs on this site come from real workspace artifacts:

- **Fusion Console** — operator console (modules, mail, API runner)
- **Daily Collection Checker** — production Microsoft Teams Adaptive Card JSON
- **Payments Event Platform** — `/api/v1/outbox/stats` + `/api/v1/payments`
- **AlgoLens** — DSA Studio two-pointer visualizer
- **This site** — React + Vite

npm install
